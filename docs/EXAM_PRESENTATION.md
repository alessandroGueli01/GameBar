# Materiale per l'esame

## Breve descrizione del progetto
GameBar è un progetto universitario che simula un sistema distribuito per la gestione di partite, giochi, tornei e statistiche in tempo reale.

## Punti chiave da spiegare
- Architettura a microservizi
- Separazione delle responsabilità tra i servizi
- Integrazione tra API REST e MQTT
- Uso di container per rendere l'ambiente riproducibile
- Valore didattico del progetto come esempio di sistema moderno

## Demo consigliata
1. Mostrare la struttura del progetto
2. Spiegare il ruolo dei microservizi
3. Mostrare la dashboard frontend
4. Illustrare il flusso di una partita o di un evento MQTT
5. Concludere con i vantaggi dell'architettura scelta

## Frasi da usare durante la presentazione
- "Il progetto dimostra come un sistema possa essere suddiviso in servizi indipendenti."
- "L'uso di MQTT permette aggiornamenti in tempo reale senza dipendere solo da chiamate HTTP."
- "La scelta di Docker rende il progetto più portabile e facile da eseguire."
